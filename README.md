# 🎯 Threads Lead Hunter — Вакансії та замовлення Хорошоп

Веб-інтерфейс та автоматизована система моніторингу постів у **Threads (Instagram)** для пошуку потенційних клієнтів, замовлень та вакансій для розробників платформи **Хорошоп (Horoshop)**.

Коли користувачі у Threads публікують дописи на кшталт:
> *"Шукаю розробника для хорошопу..."*  
> *"Потрібно перенести 4000 товарів з Prom на Хорошоп..."*  
> *"Хто робить сайти на Horoshop? Потрібна кастомізація фільтрів та підключення оплати частинами..."*

— система автоматично виявляє цей допис, додає його у ваш робочий кабінет, розраховує релевантність, підсвічує ключові слова і (за бажанням) миттєво надсилає сповіщення у ваш **Telegram**!

---

## ✨ Основні можливості

- 🔍 **Автоматичний моніторинг Threads:**
  - Пошук за ключовими фразами (`шукаю розробника для хорошопу`, `хорошоп робота`, `інтеграція хорошоп`, `horoshop developer` тощо).
  - Підтримка кількох пошукових провайдерів:
    1. **DuckDuckGo Web Search** (безкоштовно, без обов'язкових API-ключів, знаходить проіндексовані дописи Threads).
    2. **Google Custom Search API** (офіційний пошук Google, 100 безкоштовних запитів на добу).
    3. **SerpAPI** (Google Search Engine з геотаргетингом на Україну).
    4. **Демо-генератор лідів (Mock)** (для миттєвої демонстрації та перевірки інтерфейсу).
- 🚫 **Фільтрація мінус-слів (Stop Words):**
  - Автоматичне виключення курсів, семінарів, вебінарів або нерелевантних дописів.
- 💬 **Миттєві сповіщення у Telegram:**
  - Підключення власного Telegram-бота в 1 клік — отримуйте сповіщення на смартфон щойно з'явився новий клієнтський лід.
  - Кнопка прямого переходу до посту у Threads, щоб першим написати клієнту в коментарі чи в приватні повідомлення.
- 📋 **Вбудований міні-CRM кабінет:**
  - Статуси лідів: **🔥 Нова вакансія**, **💬 Відгукнувся**, **🚀 В роботі**, **📦 В архіві**.
  - Особисті замітки до кожного допису (наприклад: *"Написав у приватні, очікую ТЗ"*, *"Бюджет 15 000 грн"*).
  - Швидке копіювання посилання на пост в один клік.
- ➕ **Додавання постів вручну:**
  - Якщо ви випадково побачили пост зі смартфона у стрічці Threads, ви можете просто скопіювати посилання та текст і зберегти його у свій кабінет.
- ⏱ **Фоновий планувальник (Cron):**
  - Налаштування частоти перевірки (кожні 10, 15, 30 хвилин або кожну годину).

## 🚀 Швидкий старт

### Вимоги:
- Встановлений [Node.js](https://nodejs.org/) (версія 18 або вище)
- Git

### 1. Встановлення залежностей:
```bash
# Клонуйте репозиторій або перейдіть у папку проекту
cd threads-job-hunter

# Встановлення залежностей для клієнта та сервера
npm run install:all
```

### 2. Запуск у режимі розробки:
```bash
npm run dev
```
- Веб-інтерфейс буде доступний за адресою: **http://localhost:5173**
- Backend API сервер: **http://localhost:5000**

### 3. Запуск у режимі продакшену (єдиний порт):
```bash
# Збірка клієнта
npm run build

# Запуск сервера (сервер віддає і API, і зібраний веб-інтерфейс)
npm start
```
Додаток буде працювати на: **http://localhost:5000**

## ⚙️ Налаштування Telegram сповіщень

1. Відкрийте Telegram та знайдіть бота **@BotFather**.
2. Відправте команду `/newbot`, оберіть ім'я та нікнейм для бота, після чого скопіюйте **Bot Token** (наприклад, `7123456789:AAH...`).
3. Щоб дізнатися свій особистий **Chat ID**, відкрийте бота **@userinfobot** або **@getmyid_bot** у Telegram та натисніть `/start`. Скопіюйте свій числовий ID.
4. Відкрийте веб-кабінет (іконка шестерні ⚙️ зверху праворуч), перейдіть на вкладку **Telegram сповіщення**, увімкніть перемикач, вставте токен і Chat ID та натисніть **"Перевірити з'єднання"**.

## 🐳 Запуск через Docker

У проекті вже налаштовано `Dockerfile` та `docker-compose.yml`:

```bash
docker-compose up -d --build
```
Додаток підніметься у контейнері на порту `5000` зі збереженням бази даних у папці `./server/data`.

## 🛠 Технічний стек

- **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons
- **Backend:** Node.js, Express, Axios, Cheerio (HTML-парсер), Node-Cron (планувальник)
- **База даних:** Вбудована швидка JSON/File-based DB з атомарним записом (без потреби встановлювати важкі СУБД)
- **Деплоймент:** Docker, Node.js
